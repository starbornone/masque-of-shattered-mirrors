# Pathbuilder 2e transfer

In Pathbuilder Web 112.0 (Feylines), **Load Character** opens saved builds and **Data → Backup/Restore** transfers Pathbuilder’s own local saves between browsers or computers. The app also offers **Share Copy of Character** for builds made in Pathbuilder. No external character-file importer was visible in the web app. [Pathbuilder Web](https://pathbuilder2e.com/app.html)

**Export JSON** sends build data out for use in other tools. The developer describes that format as an export for external integrations, including Foundry. **Custom Pack** imports rules content such as custom feats, spells, and heritages. [JSON export announcement](https://www.patreon.com/redrazors/posts/update-42143091) · [Custom Pack announcement](https://www.patreon.com/redrazors/posts/pathbuilder-2e-68465817)

The November 11, 2026 check covered the live web app and the developer’s public documentation. The native mobile apps were not tested. No supported way to import a third-party player build was verified, so Masque defers Pathbuilder export until an external character import format is available.
